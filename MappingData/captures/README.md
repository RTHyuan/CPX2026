# Pro 短时真实采集

2026-11-22，在已连接的 iPhone 17 Pro 上用版本 1.0（19）的 `--check-local-map` 进行 8 秒传感器采集窗口，不调用模型、不播报行走指令。

`pro-local-map.json` 是真实 ARKit 会话数据：100 个正常追踪帧、3 个轨迹采样、212 个 LiDAR 深度来源点、1 个地标；报告见 `pro-capture-report.json`。采集期间相机发生中断，不能作为持续追踪或长距离建图验证。未与 LEVEL G／1／2 扫描图配准，不能表示手机在楼层图中的位置；点云仅为短时局部观测，不是全楼地图或安全通行区域。
