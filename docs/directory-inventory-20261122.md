## 哪些内容可以重新生成

`Build/`、`ModuleCache/`、`Index/`、`SDKExplicitPrecompiledModules/`、SwiftPM构建产物通常可以由源码重新生成。`.xcresult`、真实传感器JSON、实拍/回放输入、集成结果及源码哈希属于验证证据，应先挑选保存。本次只做清点，未删除或清理任何内容。
