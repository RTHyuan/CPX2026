# PathSense 现场反馈与验证 · 2026-11-22

## 用户反馈与原因

展位起点使用「带我去教室门口」。公共走廊可输入房号、医院科室或商场店铺。旧版把两条横向明暗边缘作为台阶，并在当前坐标系中持续保留停步状态。普通目标的页面也缺少寻找另一条平坦通道的入口。走廊里，地面证据随持机角度变化，多个不同措辞的提醒会互相打断。

## 本轮交互

- 抬起手机看门牌或图形标识时，应用按拍摄位姿记下牌的位置。普通话按位读房号。云端可以补充图标和本牌箭头的含义。
- 旋转手机后按当前方向提示。仅有旧视线、且用户已横移时，请用户用手机再看一眼。
- 点击「我已在公共区域」后可以直接寻找门牌或走廊指示。导航页的「重新寻找平坦过道」适用于各类目的地。
- 灯光、纹路、人员和真实落差的效果由像素回放与陪同实走验证。恢复前进需要新鲜的本地通行证据。现场，请继续使用惯常的出行辅助。

## 云端接入

在演示 Mac 的工程根目录运行 `./Scripts/start-navigation-proxy.sh`，同一 Wi-Fi 的 iPhone 在「使用说明 → 云端视觉」输入本轮完整配对地址并允许关键帧。界面显示本次连接结果。正式图文推理使用 `deepseek-flash`。测试配置保存在 Mac 的私有源码 `Proxy/local_settings.py`，也可用 `DEEPSEEK_API_KEY` 覆盖。项目测试牌允许用于本轮真云端验证。

## 现场反馈对应的修复

| 现场现象 | 当前处理 |
|---|---|
| 手轻微抖动后反复喊停，抬手机看牌时反复要求看地面 | 在原地找线索时保持读牌或提示环顾。发出过前进指令后才因通道失证撤回指令。人员和已测得的落差能立即抢占。 |
| 走廊里刚读到门牌，画面与重听按钮又变成环顾 | 将标牌按拍摄位姿记入会话地图。读牌投票只比较与标牌有关的内容，保留仍在当前视角的牌面与正在朗读的句子。 |
| 教室内的平面横纹导致台阶状态锁死 | 横纹和系统粗分类只让相应方向保持未知。确认落差后记住该方向，可原地查看其他方向。侧向平坦通道取得连续三帧通行证据后重新对准，再确认手机朝向身体前方。 |
| 看到房号也看到 Staff Only | 将重复观察到的限制文字与牌面方位关联。转向其他通道可以继续搜索，转回该入口再次提示。 |
| 只看到图标或门牌出画 | 对同帧云端回复回填标识含义和箭头。转身后按当前位置重新指牌，只有旧视线且横移后要重新观察。 |

就地扫尽仍无可确认的过道时，只提示一次。移椅、行人、低凳和下行台阶的实机误报与漏报必须结合人工参照和应用事件登记。[现场操作和测量项目](air-field.md)
