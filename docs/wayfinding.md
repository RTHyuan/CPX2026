# 用 PathSense 找到目的地

在首页输入房号、科室、店铺名称或公共设施，点「开始导航」。首次使用时允许后置相机。站定并慢慢转动手机，找到标识后稍作停留。每到一处新标识，把镜头转过去即可继续同一次导航。

| 看到的现场线索 | 手机如何引导 |
|---|---|
| 室内门、入口或出口 | 提示镜头中疑似门的位置。按一步提示接近并核对同一个入口。通过后观察门外环境，或确认已进入公共区域，再寻找最终目的地。已经在大厅或走廊时可直接扫目录。 |
| 独立房号 | 记住首次和最近的门牌。当前楼层需要楼层牌或「您在此」标记确认。 |
| 医院目录、商场索引、房号范围 | 读取目标所在行、同栏楼层标题、分区和箭头。遇到同名的不同楼层或相近名称时，列出牌上读到的选项。 |
| 电梯、楼梯和楼层牌 | 读出标明的方向。在换层点核对后前往目标楼层，离开电梯再扫楼层牌。到错层会提示当前层和目标层。 |
| 路口标识、独立门牌或店招 | 跟踪目标所在行的箭头。读到独立标识会请你核对，点「已核对，确认到达」后结束采集。 |

例如，从房间找 402 时，可以先扫到门，出门后扫到 208。目录若标明 `401–420` 在 `4F`，就寻找电梯或楼梯指示，到站核对 `4F`，再沿本层标识找 402。医院和商场使用同一个入口，输入实际科室或店名即可。

开启首页的「语音播报」后，点「开始导航」就会听到目的地和第一步。房号 `208` 读作「二零八」，楼层 `4F` 读作「四楼」，`B1` 读作「地下一层」。开始时有一下振动，读到新路牌时振动更明显，确认到达时有成功触感。同一块牌保持在画面里只提醒一次。

「重听」会按当前位姿核对方向和牌面。已用完的「向前迈一步」不能重播。「暂停」会关闭相机，「继续」沿用行程，重新核对眼前画面。进入后台也会暂停。「重新确认位置」适用于走错方向或更换区域。左上角返回可换目标，右上角问号可打开使用说明。

在已配置直连的 iPhone 上，Wi-Fi 或蜂窝网络均可用于云端视觉。进入「使用说明 → 云端视觉」，可先点「用公开门照测试连接」检查当前网络。点「启用云端视觉」并允许发送后，手机才会把现场关键帧、目的地和位姿摘要发给 DeepSeek。在显示配对地址输入框的设备上，先填入演示 Mac 提供的地址。随时可点「切换到仅本机」。

光线、遮挡、远距离小字和标识缺失都会影响读数。需要时可询问服务台，行走和避障继续使用日常的出行辅助。

## 展桌试用

用另一块屏幕全屏翻动展桌 PDF，或将标牌按页打印。让 iPhone 镜头持续观察牌面。第 1–6 页核对相似房号和区间，第 7–13 页寻找 402，第 14–19 页寻找眼科，第 20–25 页寻找松间书屋。这些是受控测试场景，实际就诊或购物时输入现场名称即可。[展桌标牌](media/field-signs.pdf)
